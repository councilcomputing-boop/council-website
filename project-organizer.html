The problem

A startup's early tools are scattered everywhere

Tasks in one app, notes in another, investor outreach in a spreadsheet, time tracked nowhere at all — no shared view of where a project actually stands.

No shared source of truth

Every team member tracked their own tasks and notes their own way, so nobody had a full picture of a project's real status.

Outreach fell through the cracks

Investor and customer conversations lived in inboxes and memory, with no record of who'd been contacted or what they said.

What we built

A full toolkit, not just a task list

Six pieces that work together in one shared workspace per team.

Group Workspaces

Every team gets its own workspace behind a short invite code — no accounts to provision by hand, just share the code.

Task Boards & Metrics

A To Do / Doing / Done board per project, plus a lightweight metrics dashboard with hand-drawn sparklines — no charting library needed.

Prompt In / Prompt Out

A one-tap timer clocks time against a project, so effort spent is visible without anyone filling out a timesheet.

Outreach CRM

Track investors, customers, and partners with a status pipeline — Draft, Pending, Responded — and send follow-ups straight from the app.

Notes & Decisions Log

A running log per project so decisions and context survive past the meeting they were made in.

Shared Resource Library

Templates and tools that any group in the workspace can use, with edits restricted to the person who added them.

How it works

From invite code to shipped project

1

Create a workspace

Start a group and get a short invite code to share with your team — no per-person setup required.

2

Add projects & tasks

Each project gets its own task board, notes log, and metrics dashboard, visible to the whole group.

3

Track time and outreach

Prompt in when you start working, and log investor or customer conversations as they happen.

4

See it all in one place

Anyone in the group can open the workspace and see exactly where every project actually stands.
